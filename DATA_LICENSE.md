# Data and redistribution

Source data and derived-data redistribution rights are governed by the originating OECD/IEA materials and any accompanying terms. This repository does not grant a blanket open-data licence over PISA, PIRLS or TIMSS data or aggregates.

Code written for this project is licensed under the repository MIT licence unless a file states otherwise. Project-authored documentation may be reused with attribution, but embedded or derived third-party data remain subject to their source terms.

Until redistribution rights are explicitly confirmed, the repository contains source/provenance metadata, hashes and generation code instead of restricted source bytes or large production aggregate bundles.

# Gecontroleerde openbare data

Deze map bevat uiteindelijk uitsluitend land-jaaraggregaten die:

1. reproduceerbaar uit de analysepijplijn komen;
2. aan `schema.json` voldoen;
3. alle relevante onzekerheids- en kwaliteitsvelden bevatten;
4. inhoudelijk en juridisch voor openbare verspreiding zijn goedgekeurd.

Studentrecords, schoolrecords, directe identificatoren en toetsmateriaal zijn
hier verboden.

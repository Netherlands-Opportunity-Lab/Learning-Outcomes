# Public statistical support for privately delivered documents

The manuscript, slide deck, page/slide images and prose-bearing generators are private-only and have been withdrawn from this public tree. The owner retains the complete byte-verified private bundle and its Drive restore proof.

The remaining aggregate tables, scientific figures, fonts, generic code and numerical review receipts are retained for scientific reproducibility. They are not the complete private document bundle. Use the public replication package entry point REPLICATE.py for result inspection and dashboard reconstruction. The historical product manifest records prior reviewed bytes; it does not authorize redistribution of the private files.

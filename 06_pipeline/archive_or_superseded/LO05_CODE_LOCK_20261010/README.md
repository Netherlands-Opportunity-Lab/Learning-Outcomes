# Historical producer code used by the certified October calculations

These 24 R files are retained for code provenance. Do not start the old launchers: the active approved-cell entry point remains root `START.R` and `06_pipeline/RUN.R`.

`SOURCE_CODE_ORIGINAL_VS_PUBLIC_SHA256.csv` maps each original producer file to the stored public copy. Copies preserve original bytes unless a personal absolute-path fallback required sanitization; those changes are explicitly marked with both SHA256 values. They do not rewrite the historical fingerprints of already produced results.

The active exact dispatcher uses the pinned local original bundle, whose identity is verified before execution. This archive makes its source code reviewable in GitHub; it does not by itself establish that a new machine can reproduce everything without the separately retained input contracts and source data. Full portable source-to-product reproduction remains an explicit release condition.

No pupil data, old unvalidated bulk results, private inventories or credentials are included.

# Publicatiestatus

De repository en huidige dashboarddistributie blijven privé. De finale productrelease gebruikt de bevroren resultatenbasis van 28 september 2026 en houdt alle lokale caveats zichtbaar.

De grote OECD/IEA-afgeleide downloadlaag wordt niet als open data in Git opgenomen zolang redistributierechten niet expliciet zijn bevestigd. De geteste distributie is exact gehasht in `../data/PRODUCTION_DATA_MANIFEST.csv`.

Technisch getest in de finale productintegratie: lokale HTTP-respons voor index, downloads, JavaScript, metadata en de finale productbasis; XML/PDF-rendercontrole voor de presentatieproducten. Niet geclaimd: volledige handmatige cross-browser/mobile QA of openbare hosting.

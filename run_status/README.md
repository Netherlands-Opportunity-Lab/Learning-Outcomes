# Learning Outcomes – live sanitized run status

This is a **public metadata-only status channel** maintained by the local
R runner. No raw console logs, data rows, local paths, participant records,
OAuth credentials or unrestricted result files may be committed here.

`run_status/latest.json` is the current sanitized view. The Git commit
history records previous published states. The producing scientific code
is versioned independently on the feature branch (eventually main once
the scientific release is accepted).

A manifest here is not a scientific release, a result validation, or a
replacement for the restricted result store. Detailed diagnostics and
larger files belong in private Google Drive; source microdata stay under
provider-approved access arrangements.

The owner can stop publication from R with `LO_GITHUB_STATUS=OFF`.
GitHub authentication for pushes is configured locally via Git Credential
Manager; secrets never belong in this repository.

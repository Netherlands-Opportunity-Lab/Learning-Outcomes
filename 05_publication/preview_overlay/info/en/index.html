Populations and outcomes

PIRLS measures reading at international grade 4 (Dutch group 6); TIMSS measures mathematics and science at this grade. PISA measures all three domains among 15-year-olds. Each survey retains its own scale. These are repeated cross-sectional samples, not followed pupil cohorts; observations are survey waves rather than annual measurements.

Choose a focus country, one of six age–domain combinations, a statistic and a breakdown. Only approved combinations are offered. Below-basic and high/advanced proficiency use different thresholds and are not complements. Exact definitions are available with each chart.

Groups and learning environments

Breakdowns cover gender, low/high SES, home language and migration. PISA SES uses the selected harmonised four-wave method; PIRLS/TIMSS use the specified books-based definition. These are different constructs. Official Home SES and joint SES–gender groups are appendix products and are not silently added to the dashboard.

Where girls cannot be identified separately, the approved source category girls + other is explicitly labelled. Lines break when that definition changes. Migration choices distinguish one or both parents born abroad, both parents born abroad, or first and second generations separately. Third generation cannot be inferred without grandparent information.

Peer charts describe class or school composition with self-exclusion. Peers below basic and high/advanced peers are separate outcomes. These descriptive associations are not causal peer effects.

Uncertainty and international references

The Uncertainty range switch is on by default. Turn it on for 95% confidence intervals around individual focus-country estimates, including group breakdowns. We use the verified standard error: estimate ± 1.96 × SE. A wider interval means a less precise estimate; it does not describe variation between pupils or every possible source of bias. The normal approximation can extend beyond 0–100% for shares; bounds are not clipped. Interval overlap is not a test of a difference. Ranks and international reference averages have no interval. See the OECD technical notes.

Dutch and English use one application, the same figures and the same results. Only text and number formatting change. Switching language preserves all selections, including the uncertainty switch. Core below-basic and high/advanced series are converted from proportions to percentages; SES and peer series are already percentages. Downloads retain input values, the scale factor, result hash and interval method.

Estimates use sampling weights, all required plausible values and the corresponding replication design. Intervals belong to individual country estimates. N is the observed analytical sample count with its definition in the download, not population size. Downloads preserve computational precision; rounding is for display.

Temporary comparisons using available results. “Choose countries” lets you select countries with any published points for the current figure. Defaults are the available high-income OECD candidates, excluding the focus. Each year/group uses only the available selected countries, with equal weights. Missing results are never filled in. Tooltips, the data table and downloads identify actual and omitted contributors; the dashed line connects adjacent available waves, including when membership changes. Missing waves and definition changes still break the line. References have no confidence interval.

A rank chart shows the focus and optionally one other country relative to the selected countries available at that point, with an explicit denominator. There is no group-rank line. Membership may differ between years, so comparisons are provisional. Completeness and balance will be reviewed once production finishes. Final rules still require complete matching years, groups and definitions for the focus. Source-admitted dashboard countries have at least three valid waves in each of the six age–domain combinations.

Replication

The ZIP contains current scripts, the R environment lock, scope decisions, source catalogues, checked dashboard aggregates and SHA-256 manifests. Run python reproduce_dashboard.py to rebuild and verify the original website runtime and data byte for byte, without pupil files. Its README explains the separate R workflow for recomputation from official sources.

Clean-room scientific replication has not yet been certified: the current R workflow also needs the original locked source bundle and the documented external SES code. That dependency, paper checks and presentation work remain open. Successful dashboard reconstruction is not certification of those tasks.

Version and downloads

Each figure offers SVG, CSV and provenance JSON, including exact cells, input/code/result fingerprints, settings and snapshot version. The public website remains fixed during local computation; it changes only after a new reviewed publication.

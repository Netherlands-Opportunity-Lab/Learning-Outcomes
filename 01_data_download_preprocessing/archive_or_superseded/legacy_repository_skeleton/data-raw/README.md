# Lokale brondata

Deze map is door `.gitignore` uitgesloten. Plaats hier lokaal verkregen
PISA-, PIRLS- en TIMSS-bestanden, maar commit ze nooit.

Registreer voor ieder bestand in `sources.yml`:

- officiële bestandsnaam en databron;
- survey, cyclus en landendekking;
- download-URL en retrieval date;
- SHA-256-checksum;
- licentie of gebruiksvoorwaarden;
- eventuele revisie- of versie-informatie.

# 01 — Data download and preprocessing

This layer documents how official source files enter the project. The final tested completion script is integrated rather than split into newly invented modules; see `current/SOURCE_FUNCTION_MAP.md` and the canonical script under `../02_analysis/current/`.

`source_registry/` contains final provenance/availability tables with local user paths sanitised. `archive_or_superseded/` preserves earlier pipeline source-discovery/geography scripts for provenance only.

Pupil microdata and restricted official source bytes must remain outside Git.
